Simple API, powerful results

Add search with just a few lines of code.

# 1. Register your app curl -X POST "https://api.cloudsearch.io/v1/auth/register" \ -H "Content-Type: application/json" \ -d '{"email": "you@company.com"}' # 2. Create an index curl -X POST "https://api.cloudsearch.io/v1/indexes/products" \ -H "Authorization: Bearer YOUR_API_KEY" # 3. Add documents curl -X POST "https://api.cloudsearch.io/v1/indexes/products/documents" \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"document": {"title": "iPhone 15 Pro", "price": 999}}' # 4. Search! response = requests.post( "https://api.cloudsearch.io/v1/indexes/products/_search", headers={"Authorization": "Bearer YOUR_API_KEY"}, json={"query": {"match": {"title": "iPhone"}}} )
